# Kalkulator Modern

## 1. Deskripsi Program
Kalkulator Modern adalah aplikasi desktop berbasis Python dengan antarmuka grafis (GUI) menggunakan Tkinter. Aplikasi ini dibuat untuk memenuhi tugas mata kuliah Analisis dan Pengujian Perangkat Lunak.

## 2. Fitur Program
- Penjumlahan
- Pengurangan
- Perkalian
- Pembagian
- Persentase
- Reset dan hapus karakter
- Penanganan kesalahan pembagian dengan nol

## 3. Teknologi
- Bahasa pemrograman: Python
- GUI: Tkinter
- Pengujian: unittest

## 4. Struktur File
- `app.py`: tampilan dan interaksi kalkulator.
- `kalkulator.py`: fungsi perhitungan.
- `test_kalkulator.py`: kode unit test.
- `README.md`: dokumentasi proyek.

## 5. Cara Menjalankan
Jalankan perintah berikut di terminal VS Code:

`python app.py`

## 6. Cara Menjalankan Unit Test
Jalankan perintah:

`python -m unittest -v`

## 7. Kesimpulan
Kalkulator Modern menyediakan operasi matematika dasar melalui antarmuka grafis. Unit test digunakan untuk memeriksa fungsi perhitungan dan memastikan kesalahan tertentu, seperti pembagian dengan nol, dapat ditangani.
